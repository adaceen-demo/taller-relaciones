# Plantilla de tarjeta CRC

Copie este archivo como `docs/crc_<clase>.md` (por ejemplo `docs/crc_fila.md`) y complételo.
Los contratos (`.h`) ya traen una tarjeta de referencia: la suya debe estar escrita con sus
palabras y explicar la relación que practica.
